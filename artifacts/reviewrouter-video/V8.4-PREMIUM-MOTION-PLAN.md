## A. Research / motion technology choice

| Technology | Application | Decision |
|---|---|---|
| Remotion `useCurrentFrame`, `spring`, `interpolate`, `Easing` | Counts, pointer, timed card hierarchy, deterministic 41s MP4 | **Use as source of truth** |
| `@remotion/transitions` (already installed) | Named reveals and sophisticated presentations | Use selected source-anchored overlays already in V8.3, not a global slideshow |
| Motion (formerly Framer Motion) | Live React website gestures / layout animation | Research reference only; browser-driven timers risk non-deterministic frame rendering |
| GSAP / Anime.js | Imperative scroll/long-authored timeline | Good for web, but do not add to this frame-sampled Remotion movie without tested seek/pause bridge |
| React Spring | Runtime physical interaction | Borrow spring principles using Remotion's built-in `spring()`; no dependency |
| Rive / Lottie | Professionally authored character, logo or cursor assets | Optional when licensed existing authored assets exist; no speculative new assets |
| RemotionUI / video-shotcraft | Motion recipes, foreground masks, physical list press, match-iris | Reuse choreography, never blindly paste an unrelated colorful preset |

## B. UX changes

1. **Cursor**: replace arrow-only `SimulatedCursor` on the GitHub sign-in scene with a signature pointer driven by cubic Bézier waypoints and physically timed spring approach, slim motion trails, magnetic target halo, precise hotspot, soft micro-press on button, one restrained click ripple. 2. **Hero counters**: at 30 FPS, each digit visibly rises from **0,0× to 9,5× / 14,7× in ~1 s**, staggered by 4–6f. Use out-quart interpolation, clamp, tabular-number layout, no overshoot beyond the advertised values; keep source attribution inside the semantic comparison line, not a competing bottom-of-screen overlay.
3. **Benchmark counters**: same ticker grammar for 9,5× and 14,7×, synchronized with their comparison bars. Values settle in one second; show actual endpoints 1:23 vs 13:06 and 385K vs 5,664K, with real Claude logo.
4. **Finding**: show code through first highlight, then fade, compress and remove the code panel over ~22f while the first GitHub-bot comment arrives; stack grows into that vacated area. CRITICAL then two MEDIUM messages retain one focus at a time. No clipping or overlap at all when second/third arrives.
5. **Comment and commit hierarchy**: remove **card-inside-card** appearance from commit history and reuse results. Single flat timeline with connected ticks / lines; results are two typographic metrics with divider, not nested rounded boxes.
6. **Footer captions**: remove repeating disclaimer/footer lines on ordinary screens. Keep only a small clear **upstream AACR-Bench source** in hero / benchmark and a single pricing qualification within the final CTA (not at extreme bottom). Other fictitious demo data visually implied by generic demo names, never presented as real customer activity.
7. **Transitions**: retain V8.3's three causal shared-element reveals (provider→repo, Full context→MCP, Tokens used→benchmark), tune short depth/blur and settle to avoid clipped text. Do not add generic random wipes or flash effects.
