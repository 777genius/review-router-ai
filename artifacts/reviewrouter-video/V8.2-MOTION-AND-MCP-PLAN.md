- Publicly useful MCP examples for review: **Sentry** (production errors), **Context7** (current API/library docs). **Custom HTTPS MCP** = user-operated integration. GitHub issue/document lookup may already be available through built-in tools; do not imply a separate mandatory GitHub MCP install. - Reviewer skills: **No breaking API**, **Keep changes small**, **Security checks**. Show as user-selected Markdown instructions, not magical quality guarantee.
