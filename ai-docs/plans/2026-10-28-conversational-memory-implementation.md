## Architecture decisions retained

The conversation feature owns the accepted operation, frozen input/output and publication state. The memory feature owns source/cohort eligibility, commands, suppression and existing Forget/drain/history behavior. Gateway/Sub2API retains selected-account custody, refresh, quota, paid dispatch and usage. GitHub, Prisma and Hindsight are adapters. The portable package contains engine mechanisms without Router/GitHub/workspace/account policy.

Three implementation refinements were added to the approved plan and ADR032:

1. **Admit the frozen product input before automatic cohort replacement.** Learning changes the memory epoch. The original order would invalidate its own admitted input. There is still one capture and one product grant; no replacement attempt or context recapture. New facts help later turns. Permitted learning can continue after a missing/malformed product answer.
2. **Capture separate audiences through the same owner.** Internal review/investigation keeps authorized private knowledge. Description and inline publication receive a separately bounded PR-reader projection before inference, with task-specific receipts. A shared implementation does not erase audience distinctions.
3. **Claim publication once before the first create.** Current source/authority/configuration and the original deadline are checked before an atomic `ready` to `unknown` claim. Lost claim/create acknowledgement is reconciliation-only. Publication completes the admitted request without extending its grant or reapplying the short recall TTL after model execution.

The R3 status repair reuses `MemoryKnowledgeService.automaticOperations` as the bodyless aggregate owner. `delivery_uncertain` preserves the same cohort epoch only for the still-current pending set; it never resends, re-extracts, reconstructs expired input or restores a superseded cohort. Later source invalidation advances the stronger fence. The API consumes the aggregate rather than reconstructing source eligibility. One domain helper owns the unchanged deterministic cohort identity at all four production call sites.

There is no new workflow platform, generic manager, inference service, semantic confidence framework, physical-delete owner or per-turn verifier. Native extraction/embedding/consolidation remains separately operator-funded; using the selected review account for a product reply does not copy customer OAuth into the memory engine.
