## #821 is dormant in production

The worker builds its progress comment runtime only when
`REVIEW_ROUTER_HOSTED_PROGRESS_COMMENT_WRITES=1` and
`REVIEW_ROUTER_PROGRESS_REPOSITORIES` is not empty. Production has the flag at
`0`, and every worker file #821 changes is a `review-progress-*` module that
only that runtime reaches (`review-v2-production-runtime.ts` is unchanged).
So the refactor is installed but does not run in production, and the progress
comment check of its record cannot be observed there. The flag was not
changed (no feature flag without an explicit owner request).

Owner note: turning progress comments on needs an explicit owner decision, a
canary repository first (only that repository in
`REVIEW_ROUTER_PROGRESS_REPOSITORIES`), and a plan for the 1,136 historical
pending and due `ReviewProgressPublicationV1` rows, which the publisher would
otherwise start working through.
