## Preserved boundaries

The normal automatic-source owner prepares its existing permissions/current source,
changed-source CAS and suppression/replay state before final recall/context capture.
The parent binds that prepared fence to its original manifest and compares it in
its existing dispatch transaction. Completed/closed SDK success is required; lost
or UNKNOWN output cannot supply observations or a child request. The strict current
source quote decoder remains independent of the action decoder. Optional missing or
invalid observations are unavailable, never invented empty success.

The actual validated selection is frozen under the existing parent row lock as
pendingObservations (manifest/selection digests and statements) before normal
admitAutomaticSelection/commands. A different branch cannot overwrite it. The
normal epoch/suppression/current-source/confirmation/maintained-ownership and native
writer gates remain. The shared authority projection includes stable entryIds, so
a maintained ownership transfer without an epoch bump is still a veto; the final
sourceLock compares the frozen digest during normal cohort admission, while
harmless pending-to-active delivery progress is excluded. Legacy automatic learn keeps prepare→preview→complete.
There is no fabricated child processing row, SDK receipt or requestEffect.

Evaluation reports explicitly identify the parent-observations mechanism and retain
old child-receipt report compatibility. One-turn receipts bind the real parent
processing/model/account/candidate identity and completed/closed observation; child
calls/receipts are forbidden. Semantic/inventory thresholds remain unchanged, and
reliability runs cannot mix inference mechanisms. No evaluation occurred in the
original source-implementation task; later actual runs are recorded below.
