## Quiet window: rule used

Strict, as in the [fourth bundled rollout](2026-11-20-bundle4.md#quiet-window-rule-used):
`busy=0` in 8 consecutive 15 s samples (live executions, any `in_progress`
ReviewRouter Actions run of a repository with an execution in the last three
days, outbox claims, publication claims, attempts, operations and operation
attempts, claimed or new completion processes, claimed progress publications,
investigation turns and leases); not between xx:07 and xx:10; every database
session with `SET LOCAL TIME ZONE 'UTC'`; a failed or hung sample resets the
count. Two additions after the reboot: a gap of more than 40 s between two
samples also resets the count (a sleeping operator machine can never stitch
a window together), and the apply command takes one more database sample on
the host itself and refuses unless it is still all zero. The repository list
gained `agent-teams-ai/agent-teams-orchestrator` and
`agent-teams-ai/engineering-foundation`, which had executions in the last
three days.
