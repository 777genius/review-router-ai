# Provider logo assets

The SVGs in this directory are decorative brand-identification marks. The
adjacent provider name is the accessible label. Logos remain the trademarks
of their respective owners; their inclusion does not imply endorsement.

## Source and reproducibility

The following files are unmodified SVGs from the [Lobe Icons repository](https://github.com/lobehub/lobe-icons),
pinned to commit `05260484d9f4de68f90cc87a634ae68fa4043efd` (MIT-licensed icon implementation).
Files are from `packages/static-svg/icons/`:

- `claude.svg` ← `claude-color.svg`
- `bedrock.svg` ← `bedrock-color.svg`
- `vertexai.svg` ← `vertexai-color.svg`
- `gemini.svg` ← `gemini-color.svg`
- `openai.svg` ← `openai.svg`
- `codex.svg` ← `codex-color.svg`
- `grok.svg` ← `grok.svg`
- `antigravity.svg` ← `antigravity-color.svg`
- `kimi.svg` ← `kimi-color.svg`
- `deepseek.svg` ← `deepseek-color.svg`
- `opencode.svg` ← `opencode.svg`
- `commandcode.svg` ← `commandcode.svg`
- `cline.svg` ← `cline.svg`
- `openrouter.svg` ← `openrouter-color.svg`
- `mimo.svg` ← `xiaomimimo.svg`

The Lobe Icons MIT license is reproduced in `LOBE-ICONS-LICENSE.txt`.
All assets are served locally; the public page does not load images from a
third-party CDN. SVGs are loaded as external `img` elements (not injected
into HTML), with no external content or active scripts.

The existing `glm.svg`, `minimax.svg` and `nvidia.svg` were previously
sourced directly from the providers and documented in
[`provider-logo-provenance.md`](../../app/dashboard/provider-logo-provenance.md).
