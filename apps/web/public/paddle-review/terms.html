ReviewRouter is operated by an individual under the brand QuantJumpPro. QuantJumpPro is a brand, not a registered company. Contact the operator at quantjumppro@gmail.com about the service, these terms, privacy, or billing questions.

2. Current service and future paid option

The current free ReviewRouter CI control plane helps connect repositories, configure workflows and review rules, and display findings, repository health, and audit information. Review execution takes place in customer-authorized CI. Depending on the selected mode, provider credentials are held in your CI or in protected server custody, and model traffic may pass through a ReviewRouter relay. Provider subscriptions, API usage, CI, and runner costs remain subject to your own arrangements.

A future, optional paid hosted API review service is proposed. For that service, ReviewRouter's backend would receive authorized pull request diffs, relevant source and review context and call model provider APIs, with provider API costs paid by the operator. Its availability, data handling, usage rates, prices, and purchase terms will be disclosed before paid use. You do not need to buy this proposed option to use the current free CI control plane.
